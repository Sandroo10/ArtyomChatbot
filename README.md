# Metro Echoes

## Project info

This is a Next.js + React + TypeScript application.

## Getting started

Requirements:

- Node.js 18+
- npm

Install and run:

```sh
npm install
npm run dev
```

Build and run production:

```sh
npm run build
npm run start
```

## Testing

```sh
npm test
```

## Tech stack

- Next.js (App Router)
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
